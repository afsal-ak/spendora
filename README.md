# Spendora

AI spend audit platform for startups and engineering teams.

Spendora helps teams analyze their AI tooling costs, identify overspending, and discover better pricing or alternative plans through personalized audit reports.

## Features

- AI tool spend analysis
- Personalized savings recommendations
- AI-generated audit summaries
- Shareable audit reports
- Lead capture system
- Public audit result pages

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- Vercel

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```txt
http://localhost:3000
```
